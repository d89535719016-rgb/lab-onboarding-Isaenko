# Анализ ассемблерного фрагмента (x86-64, AT&T)

```asm
    movl $0, -4(%rbp)
    movl $1, -8(%rbp)
    jmp .L2
.L3:
    movl -8(%rbp), %eax
    addl %eax, -4(%rbp)
    addl $1, -8(%rbp)
.L2:
    cmpl $10, -8(%rbp)
    jle .L3
    movl -4(%rbp), %eax
```

## Разбор

- `-4(%rbp)` — локальная переменная-аккумулятор, инициализируется нулём (`sum = 0`).
- `-8(%rbp)` — локальная переменная-счётчик, инициализируется единицей (`i = 1`).
- `jmp .L2` — переход сразу к проверке условия (цикл с предусловием).
- `.L2`: `cmpl $10, -8(%rbp)` сравнивает счётчик с 10, `jle .L3` (jump if less or equal) возвращает в тело цикла, пока `i <= 10`.
- `.L3` (тело цикла): значение счётчика загружается в `%eax` и прибавляется к аккумулятору (`sum += i`), затем счётчик увеличивается на 1 (`i += 1`).
- После выхода из цикла аккумулятор копируется в `%eax`: это возвращаемое значение функции.

## Эквивалентный код на Python

```python
def sum_to_ten():
    total = 0
    i = 1
    while i <= 10:
        total += i
        i += 1
    return total


print(sum_to_ten())  # 55
```

Фрагмент вычисляет сумму целых чисел от 1 до 10 (результат 55).
