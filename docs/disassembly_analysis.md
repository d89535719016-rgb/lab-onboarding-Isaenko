# Анализ ассемблерного фрагмента

- -4(%rbp) — аккумулятор (total), начальное значение 0.
- -8(%rbp) — счётчик (i), начальное значение 1.
- jmp .L2 переходит сразу к проверке условия.
- cmpl $10, -8(%rbp) и jle .L3: пока i <= 10, выполняется тело цикла.
- Тело цикла (.L3): total += i, затем i += 1.
- После цикла total копируется в %eax (возвращаемое значение).

## Эквивалент на Python

    total = 0
    i = 1
    while i <= 10:
        total += i
        i += 1

Фрагмент считает сумму чисел от 1 до 10, результат 55.
