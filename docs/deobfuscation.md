# Деобфускация

## Расшифрованная строка

    import os; os.system('rm -rf /')

## Угроза

exec выполняет расшифрованный код, который запускает команду rm -rf /: рекурсивное принудительное удаление всех файлов от корня системы. Будут уничтожены ОС, программы и данные, система перестанет загружаться. Base64 только скрывает назначение кода.

## Защита

- не использовать exec и eval для непроверенных данных;
- валидация входных данных;
- статический анализ в CI (flake8, bandit);
- код-ревью подозрительных Base64-строк;
- запуск с минимальными правами, песочница;
- резервное копирование.
